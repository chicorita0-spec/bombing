# 피즐리베어 FINAL HIT v4

`index.html`을 Chrome 또는 Edge로 열면 실행됩니다.

## v4 변경점
- 바밍 SD 게임 스프라이트 적용
- 대기/사격 이미지가 실제 공격 때 교체됨
- 피즐리베어 대기/피격/사망 스프라이트 적용
- FINAL HIT 화면에 승리한 바밍과 쓰러진 보스 표시
- 보라색 폐허 배경 및 기존 전투 이펙트 유지

## 밸런스 수정
우측 아래 톱니바퀴에서 보스 HP, 최소/최대 데미지, 연사 횟수와 속도를 직접 수정할 수 있습니다.
데미지는 최소~최대 정수 중 완전 균등 랜덤입니다.

## 외부 연동용 함수
```js
window.raidAttack({ nickname: '홍길동', amount: 1000 });
```
100은 1회, 1000 이상은 설정된 연속 공격 횟수로 실행됩니다.
